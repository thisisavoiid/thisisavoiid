### About me

Games Programming student at SAE Institute Bochum, working toward becoming a .NET developer with game development as my core focus. I spend most of my time in C# and Unity, write automation scripts and Discord bots in Python, and run a Linux home server for testing and hosting my own tools.

Outside of code I produce electronic music under the alias **AVØIID** — dark, minimal, and a good excuse to debug audio plugins instead of gameplay code.

**Currently building:**
- A Limbo-style underwater exploration game
- Tools and internal systems around a small experiences company
