## `> whoami`

I'm Jonathan — a Games Programming student at **SAE Institute Bochum**.

Most of my time goes into **C#**, **Unity** and **.NET**, with Python and C++ filling in the gaps when a project calls for it.

I like building things from the ground up: gameplay systems, tools, bots, prototypes and reusable architectures. I'm especially interested in keeping larger projects modular instead of turning everything into one giant manager class.

Outside of game development, I make electronic music as **AVØIID**.
